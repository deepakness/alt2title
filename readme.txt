Easily copy image alt texts to titles in your WordPress media library with bulk processing capabilities.

== Description ==

ALT2Title is a simple yet powerful plugin that helps you maintain consistency between your image alt texts and titles. It allows you to copy alt texts to image titles either individually or in bulk, making it perfect for organizing your media library.

**Key Features:**

* One-click processing of all images in the media library
* Bulk action in the media library for processing selected images
* Easy-to-use interface under the Tools menu
* Automatic skipping of images without alt text
* Clean, lightweight code with no external dependencies

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/alt2title` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Use the Tools->Alt to Title Copier menu to access the plugin

== Frequently Asked Questions ==

= Will this plugin modify my original images? =

No, this plugin only updates the title metadata of your images. It doesn't modify the actual image files.

= Can I undo the changes? =

The plugin doesn't currently have an undo feature. We recommend backing up your database before processing large numbers of images.
